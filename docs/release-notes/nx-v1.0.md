# Metroid: Zero Mission NX 1.0

- Added centered widescreen gameplay with extra visibility on both sides and balanced borders in small rooms.
- Fixed sprites appearing late, corrupted graphics near doors, and background fragments beyond room edges in Wide mode.
- Fixed minimap clipping and kept item, area, and save prompts centered.
- Restored the Yes/No labels when confirming a file erase.
- Kept original framing for menus, cutscenes, and room transitions.

## Install or update

Extract `Metroid-Zero-Mission-NX-1.0.zip` to your SD card. The app belongs at `switch/mzm/mzmnx.nro`. Supply your own compatible ROM at `switch/mzm/mzm.gba`; no ROM is included.

Existing in-game saves, settings, and achievement caches remain usable. Older save states require their matching build and cannot be loaded in 1.0. Continue from an ordinary in-game save.
