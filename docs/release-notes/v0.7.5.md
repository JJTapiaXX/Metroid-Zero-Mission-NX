- Saving no longer drops the game to 30 fps, and the save file is safer: it is written in the background, whole, and the save before it is kept.
- If the save file cannot be written, a message on the bottom screen says so.
- New options: automatic Space Jump and automatic bomb jump (Options > Controls).
- Quick morph is smoother: crouching and morphing no longer look like two separate movements.
- The map, the remap list and the set chooser no longer move when you only tap them.
- The FPS counter on the top screen shows five small numbers instead of one large one.
